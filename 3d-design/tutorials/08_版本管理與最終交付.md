# 10-H｜從完成模型到可維修、可重印的產品資料包

> 目標：讓第一次列印不是一次性的作品，而是一個能維護、升級、重印的工程專案。

## 一、不同檔案要做什麼

| 格式 | 用途 | 需要保留嗎 |
|---|---|---|
| \`.FCStd\` | FreeCAD 的可編輯工程主檔 | **必要** |
| \`.py\` / \`.FCMacro\` | AI 建模／修改腳本 | **必要**（若用腳本產生） |
| \`.step\` | 交換、檢查、轉交其他 CAD 軟體的工程實體 | 建議 |
| \`.stl\` | 每個外殼零件的網格幾何，用於切片 | **必要** |
| \`.3mf\` | Bambu Studio 切片專案／列印設定 | **必要**（實際列印之後） |
| \`.pdf\` | 尺寸圖、裝配與維修說明 | 建議 |
| \`.jpg\` / \`.png\` | 印件照片、實測與裝配證據 | 建議 |

## 三、上 GitHub 前檢查

- 不要上傳公司帳號密碼、裝置內網 IP、Wi-Fi、API Key、機台登入或任何公司機密設定。
- 若某張照片或 CAD 來自公司內部資料，先確認能否放公開 GitHub。建議只上傳自己開發的測試模型與非機敏規格。
- FreeCAD 可編輯原檔是工程主版本；STL 不應是唯一資料。
- STL 必須確認幾何封閉、單位、可切片，並配合實際列印與裝配驗證才可標示「可用」。
- 重要大型原生檔案若超出 GitHub 一般推送習慣，評估 Git LFS 或公開／私有儲存策略。

## 四、完成條件（不是外觀好看就算）

- [ ] PCB／LCD／馬達所有關鍵尺寸已量測，來源清楚
- [ ] 可拆外殼完成、供電口均在背面
- [ ] FreeCAD 原生檔案可以重開與修改參數
- [ ] 各零件 STL 單獨能在 Bambu Studio 切片
- [ ] ABS 試印無重大翹曲，孔距與接頭能實際裝配
- [ ] SG90 角度與供電走線無干涉
- [ ] 有至少一輪「量測 → AI 修改 → 再印」的變更紀錄
- [ ] 3MF、零件清單、組裝／維修說明已保存

## 五、接下來要做什麼

你先完成 10-A ～ 10-D 的入門練習，不需要等 SG90 等配件全部買齊才能開始**LCD 開孔試片**。但要做最後整機殼體，就需要全部零件的實際機構尺寸與電源配線安排。

完成後把測試結果與失敗照片交給 AI，讓它依實測更新參數，再做下一版，而不是重新從頭畫圖。
