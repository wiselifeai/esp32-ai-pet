# 10-F｜Bambu Studio：將 FreeCAD STL 送到公司 P2S 試印 ABS

> 目標：你不必會複雜切片，只要能正確選機器／材料、看懂預覽、避免錯誤列印。
> 準備：公司已核准使用的 Bambu Lab P2S、ABS 線材、實際測試片 STL。

## Step 1：先確認安全與設備

- [ ] 已確認公司允許使用 P2S 列印本專案，且設備場域有適當通風／局部排氣。
- [ ] 已核對 ABS **品牌與系列**，線材保存狀態與公司實際使用的 ABS Profile。
- [ ] 已確認 P2S 的噴嘴尺寸、列印底板、實際線材，以及操作人員是否具備必要安全訓練。
- [ ] 若機器有內建濾網／外殼，**仍不得當作無需通風的證明**。

ABS 會有揮發性物質及微粒排放；不應在不適當的密閉辦公環境列印。請遵守公司環安衛規範，勿擅自修改機器 G-code 或安全裝置。

## Step 2：在 Mac 安裝並開啟 Bambu Studio

1. 從 [Bambu Studio 官方網站](https://bambulab.com/en/download/studio)下載 Mac 版本並安裝。
2. 初次設定選擇 **Bambu Lab P2S**；若選不到相對應機型，先更新到官方支援版本。
3. 依公司實際裝設噴嘴設定（原廠標配 0.4 mm，**但仍需確認現場**）。
4. 選擇公司使用的 ABS 對應 Profile，**不要誤選 PLA**。若是第三方 ABS，先比對廠內已驗證的材料設定。

## Step 3：匯入模型與預覽

1. 打開 Bambu Studio → **Prepare（準備）**。
2. 用 **Import／Add** 選擇 FreeCAD 匯出的 \`.stl\`；檢查尺寸單位是否是 **mm**。
3. 在底板視圖確認：零件沒有埋入底板、超出成形空間、不合理縮放或彼此重疊。
4. 決定接觸底板的面；對 LCD 邊框等外觀件，優先避免重要外觀面留下支撐痕跡。
5. 依官方或公司 ABS Profile 檢查壁厚、支撐、Brim／附著需要、列印時間與耗材。
6. 切換 **Preview（預覽）**，查看路徑與支撐；若空洞被填滿或薄壁不見，要回 FreeCAD 修改而不是直接列印。
7. **Save Project** 儲存 \`.3mf\`；STL 是幾何、3MF 則保存切片專案資訊，兩者都保留。

## Step 4：材料設定以線材版本為準

如果公司使用 **Bambu 原廠 ABS**，原廠參考溫度可能在噴嘴 240–270°C、熱床 80–100°C 範圍；**不是固定設定值**。若是其他品牌，必須使用相符品牌／材料的原廠或廠內 Profile。

首件若使用 0.4 mm 噴嘴，可從相容 **0.20 mm** 層高 Profile 起步，之後再依尺寸、品質、支撐與翹曲調整，不自行硬改風扇、機器 G-code 或環安衛設定。

## Step 5：先試印小件

只選一個簡單且必要的測試片：

- **第一件：LCD 開孔／PCB 固定柱**
- 第二件：USB-C + 獨立 5V **背面**開孔
- 第三件：SG90 馬達支架（等馬達尺寸確認）
- **最後**才是完整外殼。

切片確認後，依公司規範在 P2S 執行列印。完成後等待適當冷卻再取件，記錄照片、實際尺寸與是否翹角。

## 常見錯誤

| 現象 | 優先檢查 |
|---|---|
| 翹角／底部脫離 | ABS 收縮、底板清潔與材料 Profile、Brim、環境穩定 |
| 孔徑偏小 | 模型尺寸、切片後孔內輪廓、ABS 實測誤差 |
| 薄壁消失 | CAD 壁厚、噴嘴線寬、切片 Preview |
| 支撐傷及外觀 | 重新調整零件方向與支撐位置 |
| 3MF 與 STL 看起來不同 | 檢查選擇的零件、縮放及切片參數 |

請先保存實際試印結果，不要將別人的 ABS 修正係數直接套用到你的 P2S。
