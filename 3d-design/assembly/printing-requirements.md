## 概念規格（必須打樣驗證）

| 項目 | 暫定設定／要求 | 驗收方式 |
|---|---|---|
| 整體 | 約 95 × 80 × 80 mm | 實際零件佔位與機構干涉確認 |
| 壁厚 | 約 2～2.5 mm | 剛性與固定柱受力測試 |
| 噴嘴 | 若設備為標配，0.4 mm | 在 Bambu Studio 比對機器設定 |
| 層高 | 可先試 0.20 mm 的 ABS 相容 Profile | 視表面和孔位精度再調整 |
| 耗材 | **ABS（公司現有耗材）**；品牌／型號尚待確認 | 優先使用匹配品牌的公司已驗證 ABS Profile |
| LCD 開孔 | 依實測尺寸 | 實際裝板、不擠壓玻璃／排線 |
| 供電口 | **只能在背面**，USB-C ＋獨立 5V | 確認插拔距離與線材拉力保護 |
| SG90 | 左右、上下雙軸 | 全行程不碰殼、不擠壓線材 |
| 組裝 | 前殼／主體／後蓋／底座可拆 | 至少一次拆裝測試 |

## ABS 材料安全與品質門檻

- [ ] 已確認列印區域具適當通風／局部排氣及公司許可；不可只依賴密閉機箱或內建濾網保證安全
- [ ] 已核對 ABS 品牌／系列及對應的 Bambu Studio Profile
- [ ] 先測試小件有無翹曲、收縮、孔位差異，再確定固定柱和卡扣公差
- [ ] 首次裝配避免過度擠壓 LCD 及 PCB；冷卻後再安全移除成品

參考：[ABS 材料專項流程](../printing/ABS-material-guide.md)。

## P2S 第一次打樣順序

1. 在 FreeCAD 建立 LCD／PCB 佔位與螺絲柱的局部試件。
2. 匯出 STL（mm），在 Bambu Studio 中匯入、選 P2S、確認耗材／噴嘴與底板。
3. 先印 **LCD 開窗＋主板固定柱試片**，檢查孔位尺寸與可拆裝性。
4. 再印 **USB-C／獨立 5V 背面接口試片**，檢查插拔與線材空間。
5. SG90 到貨後印 **伺服支架試片**，測試轉軸及行程干涉。
6. 所有測試片合格後再列印完整外殼，保留 Bambu Studio **3MF** 專案與 CAD 原始檔。
