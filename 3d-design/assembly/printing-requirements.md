# 外包 3D 列印詢價與交付檢查表

狀態：**規劃模板，尚未送印**。

## 給廠商的資訊

- 產品：AI 桌上型寵物可拆裝外殼，小件精密裝配。
- 列印技術：優先詢問 FDM；第一版 PLA 打樣，必要時詢問 PETG 差異。
- 單位：**mm**。提供各零件 STL（非組合成一個檔），必要時提供 STEP 供檢查。
- 每件的預計數量：待依模型列單。
- 先做局部尺寸測試片（LCD 開窗、USB 背面開口、螺絲柱、SG90 支架），通過後才完整下單。
- 特別要求：**正面不開電源孔；背面保留 USB-C 與獨立 5V 供電孔位**。
- 外殼可拆裝維修；需要雙軸伺服活動空間和導線固定／拉力保護。
- 建議壁厚初始值約 2.0～2.5 mm；最終依材料、強度、廠商建議修正。

## 詢價時向廠商確認

- [ ] 接受的格式、STL 單位（mm）、是否可依 STEP 比對尺寸
- [ ] 目標孔徑／卡合的可達精度與建議補償量
- [ ] 列印方向、支撐位置與可見面的表面品質
- [ ] 材料／顏色、耐熱和剛性選項
- [ ] 每個零件的費用、打樣／正式件費、運費與交期
- [ ] 是否提供尺寸檢查／不合格件重印機制
- [ ] 細小固定柱與機械接觸面能否可靠成形
- [ ] 後處理或螺絲／銅螺母熱熔等服務是否需要另計

## 收到列印件後

- [ ] 前殼與螢幕開窗位置符合
- [ ] 後方兩路供電接頭可插拔，線材不被夾到
- [ ] 螺絲孔／卡扣／維修蓋可重複拆裝
- [ ] 馬達在預期角度內沒有撞擊外殼
- [ ] 喇叭孔與麥克風孔沒有被支撐材料堵住
- [ ] 結構無明顯分層、裂縫、嚴重翹曲
- [ ] 拍攝並記錄需要修正的尺寸

## 模型交付檔案（完成時提供）

- 前蓋、後蓋、主體、馬達支架、底座：各自 STL。
- FreeCAD 原生模型（.FCStd）及 STEP 組裝交換模型。
- 尺寸圖（PDF）、組裝順序、零件清單與本需求文件。
