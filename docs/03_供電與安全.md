# 供電與安全（v1.1）

> 本文件是設計要求，**不是可以直接照接的最終接線圖**。本階段只有 ESP32 主板，先用 USB-C 資料線連接 Mac；不接馬達、不拆裸線供電。

## 後續兩路供電

- **ESP32／LCD：** 經板上 USB-C 供電，開發時由 Mac USB-C／USB 集線器供應。
- **SG90 馬達 ×2：** 獨立穩定 5V、建議至少 2A 的合規 USB 電源，經額定適當的取電線與 PCA9685 的伺服供電端子。
- ESP32 和馬達 **共用 GND**、控制訊號相連，但兩組獨立 5V 正極不直接相接。
- PCA9685 **VCC 是邏輯供電**、**V+ 是馬達供電**；接法必須先核對購入版本原理圖。
- SG90 啟動或卡住時瞬間電流可能變大：5V/2A 是初估，不是兩顆同時動作保證。
- 470µF/16V 電容需確認極性與固定接法；新手尚未掌握之前，先不要裸接。
- **不得**將馬達大電流走 400 孔麵包板的細導電軌；不以 ESP32 3.3V 腳位供電給 SG90。
- 修改配線前先拔除電源，外殼內裸露導線需固定、絕緣並做拉力保護。
- **3D 外殼正面不得有電源入口**；預留背面兩路電源線的孔位。市電供應器一律置於殼外。
- 若未來改電池，需另開電池保護、充電管理及供電熱設計專題，不能直接把鋰電池接上馬達。

## 通電前清單（馬達實作時才使用）

- [ ] 馬達獨立 5V 電源實測正常
- [ ] 線材與配線端子額定符合 ≥2A
- [ ] 已確認電源正負極與 PCA9685 VCC／V+ 的分別
- [ ] 已確認 ESP32 與伺服電源共地，但沒有短接兩路 5V
- [ ] 馬達機構有角度限制，無卡住與擠壓
- [ ] 背部電源孔、拉力保護與拆裝方向符合設計
