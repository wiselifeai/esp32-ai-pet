# 硬體架構（v1.1）

## 本階段只需要主板

**Waveshare ESP32-S3-LCD-1.47B-M，SKU 31031** 已購買。內建 ESP32-S3、1.47 吋 172×320 ST7789 LCD、Wi-Fi、QMI8658 六軸感測器、RGB LED、TF 卡槽。先做序列埠、LCD、動畫、Wi-Fi、LLM 文字顯示；麥克風／伺服馬達待後續。

原廠規格：[ESP32-S3-LCD-1.47B](https://docs.waveshare.com/ESP32-S3-LCD-1.47B)。

## 系統訊號流

\`\`\`text
使用者問題（先寫死在程式，之後可從 Serial 輸入）
  → ESP32（Wi-Fi 2.4GHz）
  → HTTPS 中介服務／Cloudflare Worker（認證 + API Key Secret）
  → LLM 服務
  ← 簡短回答文字（建議 ≤100 字）
  → ESP32 Serial Monitor → LCD 文字區（先英文、再繁中）
\`\`\`

以後可擴充 INMP441（I²S 收音）、MAX98357A + 8Ω/1W 喇叭（I²S 播放）、PCA9685（I²C 控制 2 顆 SG90）、3D 列印機構。ESP32 **不能在板上直接運行雲端大型 LLM**。

## LCD 已確認腳位（以 Waveshare 官方規格為準）

| 功能 | GPIO |
|---|---:|
| LCD MOSI | 45 |
| LCD SCLK | 40 |
| LCD CS | 42 |
| LCD DC | 41 |
| LCD RST | 39 |
| LCD 背光 | 46 |
| 板載 RGB LED | 38 |

**不要**把這些腳位隨意配置給音訊與馬達。實際另有 TF 卡、QMI8658 占用部分 GPIO；其餘接腳要按官方原理圖與擴充接頭核實。

## 重要限制

LCD 預設英文字型通常**不含足夠繁體中文字形**，不能把能顯示英文等同於已能顯示繁體中文。先用 ASCII 測通 LCD 與 LLM，再導入繁中字型（例如 LVGL 字型子集）。網路失敗、LLM 逾時、長回答溢出時，都需要顯示容錯畫面。
