# PICO PET LAB｜互動學習網頁使用說明

## 網站入口

網站原始碼位於本 GitHub Repository 的：
- `index.html`：學習首頁
- `lessons/01.html`～`lessons/11.html`：11 堂獨立 HTML 課程
- `assets/style.css`：RWD 與深色模式樣式
- `assets/courses.js`：課程內容資料庫
- `assets/app.js`：練習模擬器、測驗、勾選、筆記、備份

**GitHub Pages 完成啟用後**，網站預期網址：
https://wiselifeai.github.io/esp32-ai-pet/

## 首次啟用 GitHub Pages（Repo 管理員操作一次）

1. 開啟：https://github.com/wiselifeai/esp32-ai-pet/settings/pages
2. 在 **Build and deployment** 下，**Source** 選 **Deploy from a branch**。
3. Branch 選 `main`，資料夾選 **/(root)**，點 **Save**。
4. 等 GitHub Pages 顯示已發布網址，從頁面點網址打開。
5. 以後每次更新 `main` 的網站檔案就會自動重新部署，不需要手動上傳 HTML。

官方說明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

> Repository 目前可能已公開；網頁內容一律不能有私人 Wi-Fi 密碼、AI API Key、Cloudflare token 或其他敏感資料。

## 使用教學

- **課程導航**：從首頁點任一堂課，或左側欄切換。
- **互動模擬器**：練習序列輸出、LCD 文字、眼睛表情、感測門檻、Wi-Fi 排錯、LLM 流程、中文分頁等。這些都是瀏覽器模擬，**不會遠端燒錄 ESP32、也不會呼叫付費 LLM**。
- **隨堂測驗**：選擇答案後立即顯示解析；答錯可以重選。
- **實作檢查**：請在實體 ESP32 上完成後才勾選。完成測驗和實作勾選才算完成一堂課。
- **筆記**：每堂課都能寫下錯誤紀錄及心得。
- **進度備份**：右上角「⇅ 進度備份」，可**匯出 JSON**，也能**匯入 JSON** 恢復。匯入會覆蓋現有瀏覽器資料，務必先備份。
- **資料儲存**：使用瀏覽器 LocalStorage，不需帳號。換裝置、清除瀏覽器資料或無痕模式可能遺失，請定期備份。
- **字體與手機**：採大字、響應式排版，支援手機與電腦；可切換深色模式。

## 優先實作路線

`L01 → L02 → L05 → L06 → L07`：
1. Arduino 上傳；
2. LCD 原廠範例；
3. Wi-Fi 基礎；
4. **LLM 回答顯示在 LCD**；
5. 繁體中文字型。

其他 L03／L04 先作為表情和動作感測的補充課程，L08～L11 等後續硬體購買與驗證。

## 限制

目前各堂程式片段包含完整範例及概念片段。凡標示「概念」「示意」的程式不保證可獨立燒錄，應以原廠可執行的完整 LCD 範例為整合基礎。整份網站目前是**課程版 v1.0，尚未完成真實 ESP32 實機驗證**。
