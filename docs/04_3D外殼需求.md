# 3D 列印外殼設計需求（v1.2）

## 目標

- 手掌大小：**高約 95 mm、寬約 80 mm、深約 80 mm**（概念尺寸、不是已完成工程圖）。
- 外觀圓潤，正面是表情與收音，不要露出 USB 或充電孔。
- **所有供電入口只在背面**，預留 ESP32 USB-C 與伺服獨立 5V 兩路接口。
- 能拆裝維修，不把 PCB、馬達及供電連線永久封死。
- 設計要能容納兩顆 SG90 的「左右轉頭／上下點頭」結構；先驗證轉動行程和干涉。

## 暫定結構

1. 前殼：LCD 開窗、麥克風收音孔。
2. 主體：ESP32、音訊模組及喇叭固定支架、整理線槽。
3. 後蓋：背面兩個電源口、可拆卸維修蓋，預留可用的開關／線材防拉設計。
4. 頭頸：上下俯仰與水平旋轉的 SG90 支架，需留足角度與螺絲空間。
5. 底座：伺服支架、配電位置、防滑墊。

## 建模前必要量測

- [ ] 主板 PCB 長、寬、厚與固定孔距
- [ ] LCD 有效顯示區及前面玻璃／排線位置
- [ ] USB-C 插頭插入後的實際深度、線材彎折半徑
- [ ] 麥克風、喇叭、PCA9685、伺服尺寸與固定孔距
- [ ] 雙軸轉動的干涉包絡與前後重心
- [ ] 外殼配線散熱、拆裝順序及螺絲位置

## 交付規格

等實體尺寸與功能驗證完成後再做 STEP／STL／3MF、爆炸圖及組裝說明。工程稿以 **mm** 為單位，外殼是否能在 95×80×80 mm 放下全部模組尚需確認，不能預先宣稱已可列印。

## 建模軟體與製造策略（2026-11-13 決議）

- **FreeCAD**：參數化工程主檔，負責 PCB／LCD／SG90 孔位、機構配置與裝配公差；保留原生 `.FCStd` 與 STEP。
- **Blender + 第三方 Blender MCP**：第二階段的可愛圓潤外觀及渲染，工程尺寸修改後須回 CAD 重新核對。
- **PrusaSlicer 選用**：可檢視列印方向、支撐與 STL；正式切片由委外廠商依機台處理。
- **外包 3D 列印**：不自行購買 3D 印表機，先送測試片（螢幕開孔、背面供電孔、馬達座），通過後再送全套 STL。
- 首版可先評估 FDM／PLA，特殊耐熱與強度需求再比較 PETG；壁厚約 2～2.5 mm 只是概念值，正式規格需依材料和裝配驗證。
- STL 以 mm 分件提供，附 PDF 尺寸圖、組裝說明、可編輯 STEP；列印品質與公差需和廠商事先確認。
