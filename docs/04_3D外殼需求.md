# 3D 列印外殼設計需求（v1.4）

## 目標

- 手掌大小：**高約 95 mm、寬約 80 mm、深約 80 mm**（概念尺寸、不是已完成工程圖）。
- 外觀圓潤，正面是表情與收音，不要露出 USB 或充電孔。
- **所有供電入口只在背面**，預留 ESP32 USB-C 與伺服獨立 5V 兩路接口。
- 能拆裝維修，不把 PCB、馬達及供電連線永久封死。
- 設計要能容納兩顆 SG90 的「左右轉頭／上下點頭」結構；先驗證轉動行程和干涉。

## 暫定結構

1. 前殼：LCD 開窗、麥克風收音孔。
2. 主體：ESP32、音訊模組及喇叭固定支架、整理線槽。
3. 後蓋：背面兩個電源口、可拆卸維修蓋，預留可用的開關／線材防拉設計。
4. 頭頸：上下俯仰與水平旋轉的 SG90 支架，需留足角度與螺絲空間。
5. 底座：伺服支架、配電位置、防滑墊。

## 建模前必要量測

- [ ] 主板 PCB 長、寬、厚與固定孔距
- [ ] LCD 有效顯示區及前面玻璃／排線位置
- [ ] USB-C 插頭插入後的實際深度、線材彎折半徑
- [ ] 麥克風、喇叭、PCA9685、伺服尺寸與固定孔距
- [ ] 雙軸轉動的干涉包絡與前後重心
- [ ] 外殼配線散熱、拆裝順序及螺絲位置

## 交付規格

等實體尺寸與功能驗證完成後再做 STEP／STL／3MF、爆炸圖及組裝說明。工程稿以 **mm** 為單位，外殼是否能在 95×80×80 mm 放下全部模組尚需確認，不能預先宣稱已可列印。

## 建模與製造策略（2026-11-13 更新）

- **FreeCAD**：尺寸與固定機構主模型，保留 `.FCStd` 和 STEP。
- **Blender + Blender MCP（選用）**：可愛外觀／曲面設計，所有更動仍回 CAD 核對孔位與裝配公差。
- **Bambu Studio（主要切片工具）**：針對公司 **Bambu Lab P2S** 匯入每個 STL、套用相符機器／耗材／噴嘴 Profile、檢查支撐，儲存實際列印 `.3mf`。
- **公司自有 P2S 列印**：已確認公司有這台設備，使用者規劃用它列印；此決策**取代原先外包列印方案**。設備現有噴嘴、耗材、使用權限及預設參數仍待核對。
- P2S 成形範圍 256×256×256 mm，標配 0.4 mm 噴嘴；已確認**ABS 為公司現有材料及第一版打樣選擇**，需先確認品牌、專用切片 Profile 與適當通風／排氣。概念壁厚 2～2.5 mm，實際依試印結果修正。
- 先印螢幕開口／背部 USB-C／固定柱／SG90 支架的**尺寸驗證件**，實際裝配成功後再印完整外殼。
- **正面禁止供電開孔，USB-C 與獨立 5V 電源必須從背面出入**。

詳見：[ABS 專項打樣與安全](../3d-design/printing/ABS-material-guide.md)｜[Bambu P2S 列印流程](../3d-design/printing/P2S-print-workflow.md)｜[零件實際尺寸表](../3d-design/specs/measurements.md)｜[試印與驗收表](../3d-design/assembly/printing-requirements.md)。

## 如何實際操作（Lesson 10 新版教學）

完整教學已分成 **10-A～10-H 八個關卡**，不要求使用者手畫 FreeCAD：

1. 找 [Waveshare 3D Structure](https://docs.waveshare.com/ESP32-S3-LCD-1.47B/Resources-And-Documents)，拍攝板子多角度照片。
2. 卡尺確認 PCB、LCD、USB、孔位，建立毫米座標。
3. 用 AI 提示詞和附件生成 FreeCAD Python Macro，所有重要尺寸集中在參數區。
4. FreeCAD 執行 Macro、保存 FCStd、匯出局部 STL。
5. 設計可拆前後殼、雙 SG90 支架與背面兩路電源口。
6. Bambu Studio 選 P2S 及公司實際 ABS Profile，先列印小測試片。
7. 實測收縮／孔距誤差，讓 AI 修改參數後再印。
8. 保存工程檔、STL、3MF、裝配與版本紀錄。
