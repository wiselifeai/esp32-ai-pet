# 3D 設計工具與委外列印流程（v1.0）
更新：2026-11-13

## 已決定的方向

我們**不購買 3D 印表機**；外殼由 AI 輔助設計，完成後以 **STL 檔交給外部 3D 列印服務商**製作，收到成品後自行組裝與測試。

**優先順序：FreeCAD →（需要外觀雕塑時）Blender + Blender MCP → 廠商切片與列印。** 現階段不需要同時熟悉三套軟體，也不必自行維護 PrusaSlicer 設定；它可選擇性用於檢視 STL 與列印方向。

| 工具 | 預定任務 | 使用時點 | 注意 |
|---|---|---|---|
| [FreeCAD](https://www.freecad.org/) | 精準尺寸、PCB 固定柱、螺絲孔、螢幕開窗、SG90 支架、拆裝結構 | 第一個 CAD 工具 | 保留原生參數工程檔與 STEP |
| [Blender](https://www.blender.org/) | 可愛圓潤外觀、曲面、材質、視覺預覽 | 機構配置確認後 | 不讓外觀修改破壞孔位、公差與裝配面 |
| [Blender MCP（第三方）](https://github.com/ahujasid/mcp-for-blender) | 讓具 MCP 支援的 AI 工具操作 Blender，協助外觀改稿 | 第二階段、經評估安裝 | 可執行 Blender Python，僅使用可信來源並備份 |
| PrusaSlicer（選用） | 檢視 STL、列印方向與支撐可能性 | 送印前 | 實際切片參數以委外廠商機台為準 |
| GitHub | 保存規格、程式、模型、組裝變更紀錄 | 全程 | 不放 API Key／Wi-Fi 密碼 |

## 固定產品要求

- AI 桌上寵物，**手掌大小**，外觀目標約高 95 × 寬 80 × 深 80 mm；僅概念尺寸，實際須量測。
- 主板：**Waveshare ESP32-S3-LCD-1.47B-M / SKU 31031**（已購買，待確認到貨及孔位）。
- 預留 INMP441、MAX98357A、8Ω 1W 小喇叭及兩顆 SG90。
- **USB-C 與獨立 5V 馬達電源入口只能放在背面，不放正面**；市電供應器留在殼外。
- 前殼／主體／後蓋／頭頸機構／底座應可拆裝維修。
- 伺服馬達 5V 獨立供電、與 ESP32 共地；配線須做固定、絕緣及拉力保護。
- 電子零件採購預算 NT$1,200；3D 設計打樣及列印費另計。

## 工作流程與驗收關卡

1. **實體量測與資料確認**：主板與顯示區、USB 插頭插入深度、PCB 孔距、SG90 轉軸、喇叭、其他模組；填寫 [零件尺寸表](../3d-design/specs/measurements.md)。
2. **工程構型**：FreeCAD 建立參數化模型，確認固定柱、拆蓋、壁厚、走線、雙軸動作範圍；完成干涉檢查。
3. **外觀優化**：必要時交由 Blender MCP 調整圓角與造型；回到 CAD 驗證裝配尺寸，保留可編輯原始檔。
4. **小件試印**：先送印 LCD 開孔、USB 背面孔位、螺絲柱、馬達支架測試件，不直接列印全套。
5. **完整送印**：每個零件分別匯出 STL（單位 mm），附 STEP 與 [列印需求／詢價清單](../3d-design/assembly/printing-requirements.md)。
6. **收到實體後試組**：核對 LCD 對位、螺絲與卡扣、USB 插拔、喇叭孔、轉軸干涉、配線安全，再決定第二版修改。

## 暫定列印策略（需與廠商確認）

- 首版偏向 FDM / PLA 打樣；若需更高耐熱與韌性，再評估 PETG。
- 殼體壁厚可先從約 2.0～2.5 mm 概念值開始，最後依受力、材料與列印方向調整。
- 卡扣間隙、孔徑公差、螺絲柱尺寸**不得僅憑通用值定案**；先向廠商確認公差能力並用測試片驗證。
- 送印時確認尺寸為 mm、每個零件的數量、表面要求、支撐痕跡位置、交期與運費。
- 暫不宣稱任何 STL 已通過 watertight、尺寸或實體列印檢驗。
