# 歷史方案｜3D 外殼委外列印計畫（已停用）

> **2026-11-13 更新：使用者確認公司有 Bambu Lab P2S，將使用公司設備自行列印。**
> 本頁為舊版委外策略保留的決策紀錄，**不再是現行操作流程**。

請以 **[Bambu Lab P2S 打樣、切片與列印流程](../3d-design/printing/P2S-print-workflow.md)** 為準。

## 原方案（封存原因）

原先規劃 FreeCAD → Blender MCP → STL 外部列印廠商；
因已能使用公司 **Bambu Lab P2S** 進行自行試印，故改為
**FreeCAD →（選用 Blender MCP）→ STL → Bambu Studio → P2S → 實測修正**。

原方案中的「詢價／交期」不再是必要前置步驟，改為確認公司設備使用權限、可用耗材、實際噴嘴及列印 Profile。

**設計要求保持不變：** 手掌大小、可拆卸維修、ESP32 LCD、雙 SG90、**USB-C 和獨立 5V 供電入口位於背面**。
