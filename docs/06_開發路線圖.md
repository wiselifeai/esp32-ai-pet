# 由零開始到 AI 桌上型寵物：學習路線 v1.1

**學習原則：先用已買的一塊 ESP32-S3 LCD 主板取得成就感，再買麥克風、馬達和列印外殼。**

| 課程 | 主題 | 需要新增硬體 | 當堂成果 |
|---|---|---|---|
| L01 | Arduino IDE、USB 與 Serial | 無 | 每秒印出 Hello Robot |
| L02 | 官方 LCD 範例與 LVGL 文字 | 無 | 1.47 吋螢幕顯示 Hello |
| L03 | 畫表情與眨眼動畫 | 無 | 表情隨時間變化 |
| L04 | 六軸 IMU | 無 | 拿起／傾斜有回應 |
| L05 | Wi-Fi 基礎與 HTTPS 請求 | 無 | Serial 收到遠端文字 |
| **L06** | **雲端 LLM 文字顯示** | **無** | **ESP32 發問 → LLM 回覆 → LCD 顯示** |
| L07 | 中文字型與文字分頁 | 無 | 文字可讀、不溢出 |
| L08 | 麥克風／喇叭的 I²S | 需購 | 能收音及播放 |
| L09 | PCA9685、SG90 單軸／雙軸 | 需購、安全供電 | 轉頭和點頭 |
| L10 | 3D 列印外殼與整機裝配 | 需購／列印 | 正面無供電孔、背面有供電入口 |
| L11 | 語音 AI 與整合測試 | 音訊模組 | 文字、語音、表情與動作整合 |

## L06 拆成 4 個可檢查的小關卡

- **06-A**：在 LCD 顯示固定字串（先英文，確保字型）
- **06-B**：ESP32 經 Wi-Fi 向 HTTPS 測試服務取得固定文字
- **06-C**：串接經驗證的代理服務，讓 LLM 產生簡短回覆（不能把 API Key 寫進公開 GitHub）
- **06-D**：顯示在 LCD 的文字區，處理過長字串、逾時與網路錯誤

詳細請見 [Lesson 06：LLM 文字顯示](09_Lesson06_LLM文字顯示.md)。
